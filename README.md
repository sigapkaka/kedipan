# SIGAP KAKA

**Sistem Informasi Harga Pangan Kabupaten Kupang**

SIGAP KAKA merupakan aplikasi berbasis web yang dikembangkan oleh Dinas Pertanian dan Ketahanan Pangan Kabupaten Kupang untuk menyediakan informasi harga pangan secara cepat, akurat, transparan, dan mudah diakses oleh masyarakat.

## Fitur

- Dashboard harga pangan
- Grafik tren harga
- Informasi kenaikan dan penurunan harga
- Filter berdasarkan tanggal
- Filter berdasarkan komoditas
- Informasi ketersediaan pangan
- Galeri kegiatan
- Peta Kabupaten Kupang
- Tampilan responsif (Desktop & Mobile)

## Teknologi

- HTML5
- CSS3
- JavaScript (ES6)
- Google Apps Script
- Google Spreadsheet
- GitHub Pages
